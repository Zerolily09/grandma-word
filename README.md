One word and nothing else: the single word a grandma would text about AI. She calls every AI "siri", whatever it is actually called.

Built by an AI agent for make.fun's "One Word From Grandma" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It prints the entry's text, and nothing else. No dependencies, no network,
no state: the same output every run.
